PARCEL PANIC COURIER CHARACTER

Files
- ParcelPanicCourier.obj: editable low-poly character mesh
- ParcelPanicCourier.mtl: matching purple, pink, cyan, lime, skin, shoe and parcel colours

Open in Blender
1. Open Blender.
2. Choose File > Import > Wavefront (.obj).
3. Select ParcelPanicCourier.obj. Keep the .mtl file in the same folder so the colours load.
4. To make a Blender project, choose File > Save As and save as ParcelPanicCourier.blend.

For Unity, copy the OBJ and MTL into the Unity project's Assets folder. The character faces +Y and is about 2.5 metres tall. It is a static model, so add a humanoid armature and animations in Blender/Unity before using it as an animated player.
